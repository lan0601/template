## 🌐 Live Project

This Laravel + React application is deployed on Railway.

🔗 Live URL: https://laravel-react-lan-production.up.railway.app/

Features:
- Scheduler system
- Calendar booking
- Admin approval workflow

Commands:
composer install
npm install
cp .env.example .env
php artisan key:generate
php artisan storage:link

php artisan serve
npm run dev
